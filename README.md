# هات‌شیر (HotShare) — طراحی شده توسط Mr.PC

اشتراک VPN گوشی با گوشی دیگر از طریق هات‌اسپات، با QR یا کد ۸ رقمی.

## تغییرات نسخه ۲٫۳
- **دریافت VPN:** اسکن و لیست وای‌فای و حالت دستی حذف شد. اگر گوشی روی هات‌اسپات میزبان نباشد، نام دقیق شبکه (و رمز در صورت معلوم بودن) نمایش داده می‌شود با دکمه‌ی «باز کردن تنظیمات وای‌فای»؛ اگر نام و رمز معلوم باشد خودکار وصل می‌شود. تغییر رمز، قطع وای‌فای یا خاموش شدن میزبان در حین استفاده با خطای مشخص اعلام می‌شود. دکمه‌ی «انصراف» واقعاً لغو می‌کند.
- **اشتراک VPN:** صفحه به سه تب تقسیم شد (وضعیت / اتصال / دستگاه‌ها). لیست همه‌ی دستگاه‌های متصل (چندکاربره) همیشه بالای صفحه است و اتصال هر دستگاه فوراً نشان داده می‌شود. وضعیت بلوتوث، VPN و هات‌اسپات جدا و دقیق بررسی می‌شود و بلوتوثِ بعداً روشن‌شده هم فعال می‌شود. پشتیبانی بلوتوث/هات‌اسپات گوشی بررسی و فقط روش ممکن (QR یا کد) نشان داده می‌شود. دکمه‌ی هات‌اسپات «روشن کردن» است.
- **خانه:** «وضعیت شما» حذف شد، متن کارت‌ها کامل دیده می‌شود، و در حال اشتراک/اتصال بودن با یادآوری ادامه‌ی کار در پس‌زمینه نمایش داده می‌شود.
- **رادار:** موقعیت دستگاه‌ها بر اساس قدرت سیگنال تغییر می‌کند و با فاصله برچسب دارد.
- **اسکنر QR:** دکمه‌ی برگشت روی تصویر دوربین خوانا شد. تغییر کد در تنظیمات هنگام اشتراک، سرور را با کد جدید دوباره راه‌اندازی می‌کند.

## تغییرات نسخه ۲٫۲
- **آموزش فقط یک‌بار و یکپارچه:** آموزش تک‌صفحه‌ای هر بخش حذف شد. حالا یک آموزش کوتاه (۵ صفحه) برای کل برنامه هست که فقط بار اول نصب خودکار باز می‌شود. بعداً فقط اگر در «منو ← عمومی» گزینه‌ی «نمایش آموزش هنگام باز شدن» را روشن کنید (یا خودتان «مشاهده‌ی آموزش» را بزنید).
- **وای‌فای میزبان (گوشی دریافت‌کننده):** اگر گوشی روی هات‌اسپات میزبان نباشد، برنامه خطا می‌دهد و ادامه نمی‌دهد؛ همان لحظه صفحه‌ی «وای‌فای‌های اطراف» باز می‌شود که خودکار و پیوسته جستجو می‌کند و با یک لمس انتخاب می‌شود. «حالت دستی» (نام و رمز) هم هست.
  - اگر نام هات‌اسپات میزبان معلوم باشد (QR/رادار/ثبت‌شده)، فقط همان پذیرفته می‌شود؛ انتخاب شبکه‌ی دیگر خطای «وای‌فای میزبان نیست» می‌دهد.
  - اتصال با رسیدن واقعی به میزبان تأیید می‌شود، نه فقط با نام شبکه.
  - لیست وای‌فای در اندروید ۱۲ و پایین‌تر به روشن بودن «مکان (Location)» گوشی نیاز دارد؛ برنامه یادآوری می‌کند.
- **میزبان:** نام هات‌اسپات در صفحه‌ی اشتراک نمایش داده/ثبت می‌شود تا در QR برود و گوشی دوم اشتباه نکند. QR و کد در یک کارت.
- **منو و راهنما صفحه‌به‌صفحه:** منو فقط ۶ ردیف است (آماده‌سازی، تنظیمات اشتراک، زبان و ظاهر، عمومی، حریم خصوصی، درباره) و هرکدام صفحه‌ی جدا دارد. راهنما هم همین‌طور (کدام را انتخاب کنم؟ / روش‌های اتصال / قدم‌به‌قدم / وای‌فای و هات‌اسپات / مشکل دارم).
- صفحه‌ی خانه و میزبان خلوت‌تر شد (متن‌های اضافه و دکمه‌های تکراری حذف شد).

## ساخت پروژه
1. Android Studio (نسخه‌ی Ladybug یا جدیدتر) نصب باشد، پروژه را Open کنید.
2. **موتور تونل (فقط یک‌بار):** در ترمینال داخل پوشه‌ی پروژه
   `./setup_native.sh`
   (نسخه‌ی 2.20.0 پین شده است؛ امضای JNI در نسخه‌های ≥ 2.7 با `boolean` است و باید با `TProxyService.java` یکی باشد).
   در SDK Manager ← SDK Tools، **NDK (Side by side) نسخه‌ی r27 یا بالاتر** را نصب کنید.
   بدون این مرحله پروژه build می‌شود و بخش میزبان کار می‌کند، ولی «دریافت» پیام «موتور تونل نصب نیست» می‌دهد.
3. Sync و Run روی یک گوشی واقعی (شبیه‌ساز برای هات‌اسپات/VPN مناسب نیست).

## تست
- گوشی A: VPN را روشن کن ← برنامه ← «Share VPN» ← Start sharing (هات‌اسپات اختصاصی برنامه خودکار ساخته می‌شود؛ اگر گوشی پشتیبانی نکرد، هات‌اسپات سیستمی را روشن کن).
- گوشی B: «Get VPN» ← نزدیک‌ترین دستگاه روی رادار ظاهر می‌شود ← لمس ← گوشی A درخواست را تأیید می‌کند ← اتصال خودکار.
- اگر دستگاهی پیدا نشد: اسکن QR (پنجره‌ی مربعی دنبال QR می‌رود) یا وارد کردن کد ۸ رقمی؛ در صورت نیاز رمز وای‌فای داخل خود برنامه پرسیده می‌شود.
- روی B آی‌پی خود را در یک سایت «my ip» ببین؛ باید آی‌پی VPN گوشی A باشد.

## انتشار در کافه بازار
- در `app/build.gradle.kts` یک `signingConfig` برای release بسازید (Build ← Generate Signed Bundle/APK ← APK). **کلید امضا را نگه دارید**، برای آپدیت‌ها لازم است.
- `applicationId` فعلی `ir.mrpc.hotshare` است؛ قبل از انتشار می‌توانید عوض کنید (بعد از انتشار قابل تغییر نیست).
- بازار آیکن ۵۱۲×۵۱۲، اسکرین‌شات و توضیحات می‌خواهد؛ از آیکن داخل `res/drawable/ic_launcher_*` یک PNG بگیرید.
- سیاست‌های بازار برای برنامه‌های VPN/پروکسی را از پنل توسعه‌دهندگان بررسی کنید. متن حریم خصوصی داخل برنامه (راهنما و درباره) هست؛ یک نسخه‌ی صفحه‌ی وب هم معمولاً لازم می‌شود.

## محدودیت‌های اندروید
- برنامه‌ها نمی‌توانند هات‌اسپات را مستقیم روشن کنند؛ برنامه صفحه‌ی تنظیمات را باز می‌کند و روشن شدن را خودکار تشخیص می‌دهد.
- گوشی میزبان باید VPN را خودش روشن کند؛ تشخیص «VPN فعال است» در برنامه نمایش داده می‌شود.
- روی گوشی دریافت‌کننده هم‌زمان نمی‌شود VPN دیگری روشن باشد (محدودیت اندروید).

## خروجی APK با GitHub Actions
فایل `.github/workflows/build.yml` با هر push (یا دکمه‌ی Run workflow) APK می‌سازد؛ از تب Actions ← آخرین اجرا ← Artifacts ← `HotShare-apk` دانلود کنید.
- نسخه‌ی debug همیشه ساخته می‌شود (قابل نصب).
- برای release امضاشده، در Settings ← Secrets این‌ها را بسازید: `KEYSTORE_BASE64` (خروجی `base64 -w0 release.jks`)، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.
